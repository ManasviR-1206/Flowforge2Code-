FlowForge AI is an AI-powered web application that converts flowcharts into clean and executable Python code. Users can either draw a flowchart using an interactive canvas or upload an existing flowchart image. The system uses OpenCV to detect flowchart shapes, arrows, and connections, OCR to extract text, and AI to understand the flowchart logic and generate equivalent Python code. Users can preview, validate, modify, and run the generated code with custom inputs and view the output. The application is designed to make programming easier for students and beginners by bridging the gap between visual logic and actual programming.
